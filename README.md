# oitopresente-changelog

Novidades públicas do aplicativo 8Presente / Qualy Sessa, no mesmo texto das notas da Google Play ("O que há de novo").

Os arquivos são gerados automaticamente a partir do `CHANGELOG.md` do aplicativo. Não edite à mão.

## Endereços

- Página: https://devengerdev.github.io/oitopresente-changelog/
- Markdown: https://devengerdev.github.io/oitopresente-changelog/CHANGELOG.md
- JSON: https://devengerdev.github.io/oitopresente-changelog/changelog.json

## Formato do JSON

```json
{
  "latest": "1.20.1",
  "releases": [
    { "version": "1.20.1", "title": "Versão 1.20.1", "items": ["..."] }
  ]
}
```

As versões estão da mais recente para a mais antiga. `version` é `null` para entradas que não são de uma versão específica.
